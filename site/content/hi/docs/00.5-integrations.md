**जो आप पहले से इस्तेमाल करते हैं, और कुछ भी ऐसा नहीं जो अभी मौजूद न हो।** कोई driver यहाँ तभी दिखता है जब रिपॉज़िटरी में उसका कोड आ जाता है — उससे पहले कभी नहीं।

हर पंक्ति बताती है कि कौन-सा हिस्सा उस तक पहुँचता है, किस पैकेज या sink के ज़रिए, और कैसे देखना है यह जानने के लिए कहाँ जाएँ।

## यहाँ से लेता है

|  | वहाँ कैसे पहुँचता है | गाइड |
|---|---|---|
| **HTTP** | SDK: `from.HTTP` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **Postgres** | SDK: `from/postgres` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **MySQL** | SDK: `from/mysql` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **फ़ाइलें** | SDK: `from.Files` — स्थानीय, S3, GCS | [Go SDK](/docs/sdk/#sources-and-destinations) |

## यहाँ उतरता है

|  | वहाँ कैसे पहुँचता है | गाइड |
|---|---|---|
| **BigQuery** | SDK: `to/bigquery` · Gateway: `bigquery` | [Go SDK](/docs/sdk/#sources-and-destinations), [Ingestion sinks](/docs/ingestion-sinks/) |
| **Postgres** | SDK: `to/postgres` · Gateway: `postgres` | [Go SDK](/docs/sdk/#sources-and-destinations), [Ingestion sinks](/docs/ingestion-sinks/) |
| **MySQL** | SDK: `to/mysql` · Gateway: `mysql` | [Go SDK](/docs/sdk/#sources-and-destinations), [Ingestion sinks](/docs/ingestion-sinks/) |
| **Redshift** | SDK: `to/redshift` · Gateway: `redshift` | [Go SDK](/docs/sdk/#sources-and-destinations), [Ingestion sinks](/docs/ingestion-sinks/) |
| **Pub/Sub** | SDK: `to/pubsub` · Gateway: `pubsub` | [Go SDK](/docs/sdk/#sources-and-destinations), [Ingestion sinks](/docs/ingestion-sinks/) |

## फ़ाइलें यहाँ

|  | वहाँ कैसे पहुँचता है | गाइड |
|---|---|---|
| **S3** | SDK: `store/s3` · Gateway: `s3://` पर `files` | [Go SDK](/docs/sdk/#sources-and-destinations), [Ingestion sinks](/docs/ingestion-sinks/) |
| **GCS** | SDK: `store/gcs` · Gateway: `gs://` पर `files` | [Go SDK](/docs/sdk/#sources-and-destinations), [Ingestion sinks](/docs/ingestion-sinks/) |

## यहाँ मॉडल होता है

|  | वहाँ कैसे पहुँचता है | गाइड |
|---|---|---|
| **Postgres** | SQL: `--dialect postgres` (डिफ़ॉल्ट) | [SQL](/docs/sql/) |
| **BigQuery** | SQL: `--dialect bigquery` | [SQL](/docs/sql/) |

## यहाँ चलता है

|  | वहाँ कैसे पहुँचता है | गाइड |
|---|---|---|
| **Docker** | हर हिस्से के लिए एक image: `areteacademy/brevis`, `brevis-gateway`, `brevis-sql` | [इंस्टॉलेशन](/docs/installation/#docker) |
| **Kubernetes** | हर step के लिए एक pod | [Kubernetes](/docs/kubernetes/), [हर step के लिए एक pod](/docs/pod-per-step/) |
| **Helm** | `deployments/helm/brevis` में मौजूद chart | [Kubernetes](/docs/kubernetes/#install-it-with-helm) |

## इनमें लिखा गया

|  | वहाँ कैसे पहुँचता है | गाइड |
|---|---|---|
| **Go** | Core, SDK, Gateway और SQL | [इकोसिस्टम](/docs/ecosystem/) |
| **Python** | `pip install brevis`: Python step में steps के बीच संदर्भ | [Python](/docs/python/) |
| **SQL** | brevis-sql के मॉडल सादी `.sql` फ़ाइलें हैं | [SQL](/docs/sql/) |
