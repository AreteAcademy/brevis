**你已经在用的，以及仅限已经存在的。** 只有当仓库里有了对应的代码，某个驱动才会出现在这里，绝不提前列出。

每一行说明由哪个组成部分、通过哪个包或 sink 连接它，以及去哪里查看具体做法。

## 数据来源

|  | 接入方式 | 指南 |
|---|---|---|
| **HTTP** | SDK：`from.HTTP` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **Postgres** | SDK：`from/postgres` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **MySQL** | SDK：`from/mysql` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **文件** | SDK：`from.Files`，本地、S3、GCS | [Go SDK](/docs/sdk/#sources-and-destinations) |

## 数据落地

|  | 接入方式 | 指南 |
|---|---|---|
| **BigQuery** | SDK：`to/bigquery` · Gateway：`bigquery` | [Go SDK](/docs/sdk/#sources-and-destinations)、[摄取 sink](/docs/ingestion-sinks/) |
| **Postgres** | SDK：`to/postgres` · Gateway：`postgres` | [Go SDK](/docs/sdk/#sources-and-destinations)、[摄取 sink](/docs/ingestion-sinks/) |
| **MySQL** | SDK：`to/mysql` · Gateway：`mysql` | [Go SDK](/docs/sdk/#sources-and-destinations)、[摄取 sink](/docs/ingestion-sinks/) |
| **Redshift** | SDK：`to/redshift` · Gateway：`redshift` | [Go SDK](/docs/sdk/#sources-and-destinations)、[摄取 sink](/docs/ingestion-sinks/) |
| **Pub/Sub** | SDK：`to/pubsub` · Gateway：`pubsub` | [Go SDK](/docs/sdk/#sources-and-destinations)、[摄取 sink](/docs/ingestion-sinks/) |

## 文件存储

|  | 接入方式 | 指南 |
|---|---|---|
| **S3** | SDK：`store/s3` · Gateway：`s3://` 上的 `files` | [Go SDK](/docs/sdk/#sources-and-destinations)、[摄取 sink](/docs/ingestion-sinks/) |
| **GCS** | SDK：`store/gcs` · Gateway：`gs://` 上的 `files` | [Go SDK](/docs/sdk/#sources-and-destinations)、[摄取 sink](/docs/ingestion-sinks/) |

## 建模所在

|  | 接入方式 | 指南 |
|---|---|---|
| **Postgres** | SQL：`--dialect postgres`（默认值） | [SQL](/docs/sql/) |
| **BigQuery** | SQL：`--dialect bigquery` | [SQL](/docs/sql/) |

## 运行环境

|  | 接入方式 | 指南 |
|---|---|---|
| **Docker** | 每个组成部分一个镜像：`areteacademy/brevis`、`brevis-gateway`、`brevis-sql` | [安装](/docs/installation/#docker) |
| **Kubernetes** | 每个 step 一个 pod | [Kubernetes](/docs/kubernetes/)、[每个 step 一个 pod](/docs/pod-per-step/) |
| **Helm** | `deployments/helm/brevis` 中的 chart | [Kubernetes](/docs/kubernetes/#install-it-with-helm) |

## 使用的语言

|  | 接入方式 | 指南 |
|---|---|---|
| **Go** | Core、SDK、Gateway 和 SQL | [生态](/docs/ecosystem/) |
| **Python** | `pip install brevis`：在 Python step 中传递 step 之间的上下文 | [Python](/docs/python/) |
| **SQL** | brevis-sql 的模型就是普通的 `.sql` 文件 | [SQL](/docs/sql/) |
