**Ce que vous utilisez déjà, et rien de ce qui n'existe pas encore.** Un driver n'apparaît ici que lorsqu'il a du code dans le dépôt — jamais avant.

Chaque ligne indique quel composant l'atteint, par quel package ou sink, et où aller pour voir comment.

## Lit depuis

|  | comment y accéder | guide |
|---|---|---|
| **HTTP** | SDK : `from.HTTP` | [SDK Go](/docs/sdk/#sources-et-destinations) |
| **Postgres** | SDK : `from/postgres` | [SDK Go](/docs/sdk/#sources-et-destinations) |
| **MySQL** | SDK : `from/mysql` | [SDK Go](/docs/sdk/#sources-et-destinations) |
| **fichiers** | SDK : `from.Files` — local, S3, GCS | [SDK Go](/docs/sdk/#sources-et-destinations) |
