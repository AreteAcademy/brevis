**すでに使っているものだけを載せ、まだ存在しないものは載せません。** ドライバがここに載るのは、リポジトリにコードが入った時点からです。それ以前には載りません。

各行は、どの構成要素が、どのパッケージまたは sink を通じてそこに到達するか、そして詳細をどこで確認できるかを示します。

## 取得元

|  | 接続方法 | ガイド |
|---|---|---|
| **HTTP** | SDK: `from.HTTP` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **Postgres** | SDK: `from/postgres` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **MySQL** | SDK: `from/mysql` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **ファイル** | SDK: `from.Files` — ローカル、S3、GCS | [Go SDK](/docs/sdk/#sources-and-destinations) |

## 着地先

|  | 接続方法 | ガイド |
|---|---|---|
| **BigQuery** | SDK: `to/bigquery` · Gateway: `bigquery` | [Go SDK](/docs/sdk/#sources-and-destinations)、[取り込みの sink](/docs/ingestion-sinks/) |
| **Postgres** | SDK: `to/postgres` · Gateway: `postgres` | [Go SDK](/docs/sdk/#sources-and-destinations)、[取り込みの sink](/docs/ingestion-sinks/) |
| **MySQL** | SDK: `to/mysql` · Gateway: `mysql` | [Go SDK](/docs/sdk/#sources-and-destinations)、[取り込みの sink](/docs/ingestion-sinks/) |
| **Redshift** | SDK: `to/redshift` · Gateway: `redshift` | [Go SDK](/docs/sdk/#sources-and-destinations)、[取り込みの sink](/docs/ingestion-sinks/) |
| **Pub/Sub** | SDK: `to/pubsub` · Gateway: `pubsub` | [Go SDK](/docs/sdk/#sources-and-destinations)、[取り込みの sink](/docs/ingestion-sinks/) |

## ファイルの着地先

|  | 接続方法 | ガイド |
|---|---|---|
| **S3** | SDK: `store/s3` · Gateway: `s3://` 上の `files` | [Go SDK](/docs/sdk/#sources-and-destinations)、[取り込みの sink](/docs/ingestion-sinks/) |
| **GCS** | SDK: `store/gcs` · Gateway: `gs://` 上の `files` | [Go SDK](/docs/sdk/#sources-and-destinations)、[取り込みの sink](/docs/ingestion-sinks/) |

## モデリングの場所

|  | 接続方法 | ガイド |
|---|---|---|
| **Postgres** | SQL: `--dialect postgres`(デフォルト) | [SQL](/docs/sql/) |
| **BigQuery** | SQL: `--dialect bigquery` | [SQL](/docs/sql/) |

## 実行環境

|  | 接続方法 | ガイド |
|---|---|---|
| **Docker** | 構成要素ごとに 1 つのイメージ: `areteacademy/brevis`、`brevis-gateway`、`brevis-sql` | [インストール](/docs/installation/#docker) |
| **Kubernetes** | ステップごとに 1 つの pod | [Kubernetes](/docs/kubernetes/)、[ステップごとの pod](/docs/pod-per-step/) |
| **Helm** | `deployments/helm/brevis` にあるチャート | [Kubernetes](/docs/kubernetes/#install-it-with-helm) |

## 実装言語

|  | 接続方法 | ガイド |
|---|---|---|
| **Go** | Core、SDK、Gateway、SQL | [エコシステム](/docs/ecosystem/) |
| **Python** | `pip install brevis`: Python ステップでステップ間のコンテキストを扱います | [Python](/docs/python/) |
| **SQL** | brevis-sql のモデルは通常の `.sql` ファイルです | [SQL](/docs/sql/) |
