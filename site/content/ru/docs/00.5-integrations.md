**То, чем вы уже пользуетесь, и ничего из того, чего ещё нет.** Драйвер появляется здесь, только когда для него есть код в репозитории, и не раньше.

В каждой строке указано, какой компонент до него дотягивается, через какой пакет или sink, и куда пойти, чтобы посмотреть, как это делается.

## Откуда забирает

|  | как подключается | руководство |
|---|---|---|
| **HTTP** | SDK: `from.HTTP` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **Postgres** | SDK: `from/postgres` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **MySQL** | SDK: `from/mysql` | [Go SDK](/docs/sdk/#sources-and-destinations) |
| **файлы** | SDK: `from.Files` — локальные, S3, GCS | [Go SDK](/docs/sdk/#sources-and-destinations) |

## Куда записывает

|  | как подключается | руководство |
|---|---|---|
| **BigQuery** | SDK: `to/bigquery` · Gateway: `bigquery` | [Go SDK](/docs/sdk/#sources-and-destinations), [Sinks приёма данных](/docs/ingestion-sinks/) |
| **Postgres** | SDK: `to/postgres` · Gateway: `postgres` | [Go SDK](/docs/sdk/#sources-and-destinations), [Sinks приёма данных](/docs/ingestion-sinks/) |
| **MySQL** | SDK: `to/mysql` · Gateway: `mysql` | [Go SDK](/docs/sdk/#sources-and-destinations), [Sinks приёма данных](/docs/ingestion-sinks/) |
| **Redshift** | SDK: `to/redshift` · Gateway: `redshift` | [Go SDK](/docs/sdk/#sources-and-destinations), [Sinks приёма данных](/docs/ingestion-sinks/) |
| **Pub/Sub** | SDK: `to/pubsub` · Gateway: `pubsub` | [Go SDK](/docs/sdk/#sources-and-destinations), [Sinks приёма данных](/docs/ingestion-sinks/) |

## Куда складывает файлы

|  | как подключается | руководство |
|---|---|---|
| **S3** | SDK: `store/s3` · Gateway: `files` на `s3://` | [Go SDK](/docs/sdk/#sources-and-destinations), [Sinks приёма данных](/docs/ingestion-sinks/) |
| **GCS** | SDK: `store/gcs` · Gateway: `files` на `gs://` | [Go SDK](/docs/sdk/#sources-and-destinations), [Sinks приёма данных](/docs/ingestion-sinks/) |

## Где моделирует

|  | как подключается | руководство |
|---|---|---|
| **Postgres** | SQL: `--dialect postgres` (по умолчанию) | [SQL](/docs/sql/) |
| **BigQuery** | SQL: `--dialect bigquery` | [SQL](/docs/sql/) |

## Где работает

|  | как подключается | руководство |
|---|---|---|
| **Docker** | один образ на компонент: `brevissh/brevis`, `brevis-gateway`, `brevis-sql` | [Установка](/docs/installation/#docker) |
| **Kubernetes** | один pod на шаг | [Kubernetes](/docs/kubernetes/), [Pod на шаг](/docs/pod-per-step/) |
| **Helm** | чарт в `deployments/helm/brevis` | [Kubernetes](/docs/kubernetes/#install-it-with-helm) |

## На чём написано

|  | как подключается | руководство |
|---|---|---|
| **Go** | Core, SDK, Gateway и SQL | [Экосистема](/docs/ecosystem/) |
| **Python** | `pip install brevis`: контекст между шагами внутри шага на Python | [Python](/docs/python/) |
| **SQL** | модели brevis-sql — обычные `.sql`-файлы | [SQL](/docs/sql/) |
