deploy it your way

On your machine, in your cluster, or on a runtime you already keep.

Open source and self-hosted: the same binary in all three places. No service of ours in between.

Docker Compose recommended

Postgres, Core, console and Gateway on one machine, to try it or to develop.

$ git clone https://github.com/AreteAcademy/brevis
$ cd brevis && docker compose up
How to

Kubernetes + Helm

The chart in the repository: migrations as a hook, one image per role, and minimal RBAC for the step pods.

$ helm install brevis ./deployments/helm/brevis \
    --namespace data --create-namespace \
    --set database.url="postgres://…" \
    --set auth.user=admin \
    --set auth.passwordHash="$(brevis hash)" \
    --set auth.secret="$(openssl rand -base64 48)"
