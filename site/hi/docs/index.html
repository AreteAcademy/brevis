दस्तावेज़

दस्तावेज़

brevis.sh को इंस्टॉल करने, समझने और चलाने के लिए सब कुछ — पहले workflow से लेकर Kubernetes डिप्लॉयमेंट तक।

शुरुआत करें

इकोसिस्टम

brevis.sh के चार हिस्से, हर एक क्या करता है, और डेटा कहाँ से होकर गुज़रता है।

इंटीग्रेशन

क्या किससे जुड़ता है: डेटा कहाँ से आता है, कहाँ उतरता है, कहाँ मॉडल होता है और यह सब कहाँ चलता है।

परिचय

brevis.sh क्या है, वह कौन-सी समस्या सुलझाता है, और कब वह सही चुनाव नहीं है।

इंस्टॉलेशन

बाइनरी कैसे पाएँ, उसे किन चीज़ों की ज़रूरत है, और इंस्टॉल सही है यह कैसे जाँचें।

क्विकस्टार्ट

शून्य से इंटरफ़ेस में चलते DAG तक, चार चरणों में।

अवधारणाएँ

Core

ऑर्केस्ट्रेटर: run शेड्यूल करता है, कतार Postgres में रखता है और हर step के लिए एक pod शुरू करता है — और डेटा को कभी नहीं छूता।

Workflows

पूरा YAML फ़ॉर्मेट — steps, निर्भरताएँ, images, संसाधन और शेड्यूल।

शेड्यूलर और कतार

दो स्वतंत्र लूप — run कौन बनाता है, कौन चलाता है, और वे अलग क्यों हैं।

हर step के लिए एक pod

हर step अपने pod में क्यों चलता है, और इससे लागत और अलगाव में क्या बदलता है।

steps के बीच संदर्भ

एक step अगले को क्या बताता है — दो environment वेरिएबल और एक फ़ाइल।

संदर्भ

CLI

Engine के बारह सबकमांड, flags, आर्ग्युमेंट और हर एक की ज़रूरतों के साथ।

पैरामीटर

एक ही workflow के दो run के बीच, फ़ाइल को बदले बिना, क्या बदलता है।

कॉन्फ़िगरेशन

हर environment वेरिएबल, डिफ़ॉल्ट, फ़ॉर्मेट और उसके न होने पर क्या होता है, के साथ।

Step runtime

Step अपनी भाषा और जिन टूल को चलाता है उनके बारे में क्या घोषित करता है — और आपको इसकी शायद ही ज़रूरत क्यों पड़ती है।

SDK और लाइब्रेरी

Go SDK

Fetcher लिखना — स्रोत से डेटा निकालना, बदलना, और गंतव्य में लोड करना।

क्लाइंट लाइब्रेरी

किसी भी भाषा का step संदर्भ और run की घड़ी कैसे पढ़ता है — और किन भाषाओं की लाइब्रेरी पहले से है।

Python

pip install brevis — steps के बीच संदर्भ, run की घड़ी और आपकी pipeline के अपने मेट्रिक्स, बिना किसी निर्भरता के।

संचालन

Console

Core का वेब इंटरफ़ेस: क्या चल रहा है, क्या चलेगा, और हर run के साथ क्या हुआ।

Kubernetes

Engine को कैसे deploy करें, किन अनुमतियों के साथ, और उसके बाद क्या जाँचें।

ऑब्ज़र्वेबिलिटी

दोनों प्रोसेस के Prometheus मेट्रिक्स, क्या देखें, और क्या जानबूझकर अनुपस्थित है।

White label

एक YAML फ़ाइल से इंटरफ़ेस का शीर्षक, ध्येय-वाक्य, लोगो और पैलेट बदलना।

Ingestion

Ingestion

एक HTTP endpoint जो डेटा उतारता है — validate, पहचान, batch, डिलीवरी। अपनी image, अपना संस्करण।

Ingestion sinks

छह गंतव्य, हर डेटाबेस रिकॉर्ड कैसे लिखता है, और image सिर्फ़ वही क्यों ढोती है जो आप इस्तेमाल करते हैं।

Benchmarks

हम gateway को कैसे मापते हैं, संख्याएँ क्या कहती हैं, और वे तीन गवाह जिनका सहमत होना ज़रूरी है।

SQL में मॉडलिंग

SQL

सादी .sql फ़ाइलें निर्भरता के क्रम में तालिकाएँ और view बन जाती हैं — workflow के step के रूप में या अकेले।
