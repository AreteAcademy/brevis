दस्तावेज़

इंटीग्रेशन

क्या किससे जुड़ता है: डेटा कहाँ से आता है, कहाँ उतरता है, कहाँ मॉडल होता है और यह सब कहाँ चलता है।

जो आप पहले से इस्तेमाल करते हैं, और कुछ भी ऐसा नहीं जो अभी मौजूद न हो। कोई driver यहाँ तभी दिखता है जब रिपॉज़िटरी में उसका कोड आ जाता है — उससे पहले कभी नहीं।

हर पंक्ति बताती है कि कौन-सा हिस्सा उस तक पहुँचता है, किस पैकेज या sink के ज़रिए, और कैसे देखना है यह जानने के लिए कहाँ जाएँ।

यहाँ से लेता है#

वहाँ कैसे पहुँचता हैगाइड
HTTPSDK: from.HTTPGo SDK
PostgresSDK: from/postgresGo SDK
MySQLSDK: from/mysqlGo SDK
फ़ाइलेंSDK: from.Files — स्थानीय, S3, GCSGo SDK

यहाँ उतरता है#

वहाँ कैसे पहुँचता हैगाइड
BigQuerySDK: to/bigquery · Gateway: bigqueryGo SDK, Ingestion sinks
PostgresSDK: to/postgres · Gateway: postgresGo SDK, Ingestion sinks
MySQLSDK: to/mysql · Gateway: mysqlGo SDK, Ingestion sinks
RedshiftSDK: to/redshift · Gateway: redshiftGo SDK, Ingestion sinks
Pub/SubSDK: to/pubsub · Gateway: pubsubGo SDK, Ingestion sinks

फ़ाइलें यहाँ#

वहाँ कैसे पहुँचता हैगाइड
S3SDK: store/s3 · Gateway: s3:// पर filesGo SDK, Ingestion sinks
GCSSDK: store/gcs · Gateway: gs:// पर filesGo SDK, Ingestion sinks

यहाँ मॉडल होता है#

वहाँ कैसे पहुँचता हैगाइड
PostgresSQL: --dialect postgres (डिफ़ॉल्ट)SQL
BigQuerySQL: --dialect bigquerySQL

वहाँ कैसे पहुँचता हैगाइड
Dockerहर हिस्से के लिए एक image: brevissh/brevis, brevis-gateway, brevis-sqlइंस्टॉलेशन
Kubernetesहर step के लिए एक podKubernetes, हर step के लिए एक pod
Helmdeployments/helm/brevis में मौजूद chartKubernetes
