ओपन सोर्स · Go में बना · सेल्फ़-होस्टेड

कच्चे डेटा से मॉडल की गई तालिकाओं तक। Go में।

ऑर्केस्ट्रेशन, एक्सट्रैक्शन, इंजेशन और डेटा मॉडलिंग — Core, SDK, Gateway और SQL — Go में एकीकृत। ओपन सोर्स, आपके cluster में, बिना ऑर्केस्ट्रेटर से डेटा गुज़ारे।

क्विकस्टार्ट से शुरू करें GitHub पर देखें

control plane

Core

शेड्यूल करता है, कतार लगाता है और हर step के लिए एक pod शुरू करता है। डेटा को कभी नहीं छूता।

SDK

अपने तरीके से डिप्लॉय करें

आपकी मशीन पर, आपके cluster में, या किसी ऐसे runtime पर जो आप पहले से चलाते हैं।

ओपन सोर्स और सेल्फ़-होस्टेड: तीनों जगह वही बाइनरी। बीच में हमारी कोई सर्विस नहीं।

Docker Compose अनुशंसित

Postgres, Core, कंसोल और Gateway एक मशीन पर, आज़माने या डेवलपमेंट के लिए।

$ git clone https://github.com/AreteAcademy/brevis
$ cd brevis && docker compose up
कैसे करें

Kubernetes + Helm

रिपॉज़िटरी में chart: hook के रूप में migration, हर भूमिका के लिए एक image, और step pod के लिए न्यूनतम RBAC।

$ helm install brevis ./deployments/helm/brevis \
    --namespace data --create-namespace \
    --set database.url="postgres://…" \
    --set auth.user=admin \
    --set auth.passwordHash="$(brevis hash)" \
    --set auth.secret="$(openssl rand -base64 48)"
कैसे करें

आपका अपना runtime

host: वाला step उस agent के पास जाता है जिसे आप चलाते हैं — जहाँ लाइसेंस, GPU या allowlist किया हुआ IP है।

# workflow के step में
host: tools

$ kubectl apply -f deployments/kubernetes/agent.yaml
कैसे करें
