# Console

> Core の Web インターフェース。何が動いていて、何が実行される予定で、各 run に何が起きたか。

*https://brevis.sh/ja/docs/console/ · brevis.sh docs (ja)*

---

インターフェースはバイナリに同梱されています。別途インストールして稼働させ続ける必要のある別サービスではありません。成功率、平均所要時間、キュー、試行履歴、そして次に実行される予定のスケジュールを備えています。

Console は `brevis serve` とともに、HTTP API と同じポート(`BREVIS_HTTP_ADDR`、デフォルトは `:8080`)で起動します。
[クイックスタート](/ja/docs/quickstart/index.md)では、`localhost:8080` で開きます。

以下の画面は、サンプルデータを使って Console から SVG で再現したものです。
スクリーンショットは使っていません。実際の Console は、本番で顧客のデータを扱っているためです。

## プロジェクト

![analytics と platform の 2 つのプロジェクト。それぞれが自分のワークフローの名前空間を持ち、どちらも衝突せずに daily_ingest を持てます。](/assets/console-projects.svg)

プロジェクトがあるため、2 つのチームが 1 つの名前で衝突することはありません。各プロジェクトがワークフローの名前空間を持つので、2 つのプロジェクトがそれぞれ `daily_ingest` を持てます。

## バイナリに同梱

フォントとバンドルはバイナリから配信されます。インターネットがなくても動作します。
