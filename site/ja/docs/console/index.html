ドキュメント

Console

Core の Web インターフェース。何が動いていて、何が実行される予定で、各 run に何が起きたか。

インターフェースはバイナリに同梱されています。別途インストールして稼働させ続ける必要のある別サービスではありません。成功率、平均所要時間、キュー、試行履歴、そして次に実行される予定のスケジュールを備えています。

Console は brevis serve とともに、HTTP API と同じポート(BREVIS_HTTP_ADDR、デフォルトは :8080)で起動します。 クイックスタートでは、localhost:8080 で開きます。

以下の画面は、サンプルデータを使って Console から SVG で再現したものです。 スクリーンショットは使っていません。実際の Console は、本番で顧客のデータを扱っているためです。

概要#

メトリクスとグラフを備えた概要です。成功率、平均所要時間、実行中のもの、次に予定されている run が 1 つの画面に収まっています。

Workflows#

検索、フィルタ、一時停止、実行を備えたワークフロー一覧です。各行に、cron、次回と前回の run、タグがあります。

1 つのワークフロー#

ステップと依存関係、パラメータ付きで実行するためのフォーム、各ステップの状態付きの DAG、そして各日がその日の最悪の結果の色になる 1 年分のカレンダーです。

実行#

run の履歴で、それぞれの試行も確認できます。状態、ワークフロー、トリガー、run が属する slot、所要時間、作成時刻があります。

1 つの run#

run の DAG をリアルタイムで表示し、エンジンが算出した自動パラメータも見られます。各ステップのコマンド、イメージ、所要時間付きのグラフと、各ステップの出力があります。

プロジェクト#

プロジェクトがあるため、2 つのチームが 1 つの名前で衝突することはありません。各プロジェクトがワークフローの名前空間を持つので、2 つのプロジェクトがそれぞれ daily_ingest を持てます。

バイナリに同梱#

フォントとバンドルはバイナリから配信されます。インターネットがなくても動作します。
