集成

什么与什么相连：数据从哪里来，落到哪里，在哪里建模，以及这一切在哪里运行。

你已经在用的，以及仅限已经存在的。 只有当仓库里有了对应的代码，某个驱动才会出现在这里，绝不提前列出。

每一行说明由哪个组成部分、通过哪个包或 sink 连接它，以及去哪里查看具体做法。

数据来源#

接入方式指南
HTTPSDK：from.HTTPGo SDK
PostgresSDK：from/postgresGo SDK
MySQLSDK：from/mysqlGo SDK
文件SDK：from.Files，本地、S3、GCSGo SDK

数据落地#

接入方式指南
BigQuerySDK：to/bigquery · Gateway：bigqueryGo SDK、摄取 sink
PostgresSDK：to/postgres · Gateway：postgresGo SDK、摄取 sink
MySQLSDK：to/mysql · Gateway：mysqlGo SDK、摄取 sink
RedshiftSDK：to/redshift · Gateway：redshiftGo SDK、摄取 sink
Pub/SubSDK：to/pubsub · Gateway：pubsubGo SDK、摄取 sink

文件存储#

接入方式指南
S3SDK：store/s3 · Gateway：s3:// 上的 filesGo SDK、摄取 sink
GCSSDK：store/gcs · Gateway：gs:// 上的 filesGo SDK、摄取 sink

建模所在#

接入方式指南
PostgresSQL：--dialect postgres（默认值）SQL
BigQuerySQL：--dialect bigquerySQL

运行环境#

接入方式指南
Docker每个组成部分一个镜像：areteacademy/brevis、brevis-gateway、brevis-sql安装
Kubernetes每个 step 一个 podKubernetes、每个 step 一个 pod
Helmdeployments/helm/brevis 中的 chartKubernetes
