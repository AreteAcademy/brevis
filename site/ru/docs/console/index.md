# Console

> Веб-интерфейс Core: что выполняется, что будет выполняться и что произошло с каждым запуском.

*https://brevis.sh/ru/docs/console/ · brevis.sh docs (ru)*

---

Интерфейс поставляется внутри бинарного файла — это не отдельный сервис, который нужно устанавливать и поддерживать. Доля успешных запусков, средняя длительность, очередь, история попыток и расписание ближайших запусков.

Console поднимается вместе с `brevis serve` на том же порту, что и HTTP API
(`BREVIS_HTTP_ADDR`, по умолчанию `:8080`). В [Быстром старте](/ru/docs/quickstart/index.md) он открывается по адресу `localhost:8080`.

Экраны ниже воссозданы в SVG по консоли, с демонстрационными данными, —
никогда не скриншоты: настоящая консоль работает с данными клиентов в
продакшене.

## Проекты

![Два проекта, analytics и platform, каждый со своим пространством имён для workflow — в обоих может быть daily_ingest, и они не конфликтуют.](/assets/console-projects.svg)

Проекты, чтобы две команды не конфликтовали из-за одного имени. Каждый проект задаёт пространство имён для своих workflow: у двух проектов может быть по `daily_ingest`.

## Поставляется в бинарном файле

Шрифты и бандлы отдаются из бинарного файла — работает без интернета.
