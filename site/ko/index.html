오픈 소스 · Go로 제작 · 셀프 호스팅

원시 데이터에서 모델링된 테이블까지. Go로.

오케스트레이션, 추출, 수집, 데이터 모델링 — Core, SDK, Gateway, SQL — 을 Go로 통합했습니다. 오픈 소스이며, 사용자의 클러스터 안에서 동작하고, 오케스트레이터를 거치는 데이터가 없습니다.

퀵스타트로 시작하기 GitHub에서 살펴보기

컨트롤 플레인

Core

스케줄링하고, 큐에 넣고, step마다 pod 하나를 시작합니다. 데이터는 절대 건드리지 않습니다.

areteacademy/brevis

Gateway로 푸시

  • webhook과 앱
  • Pub/Sub 곧 지원
  • Kafka 곧 지원
  • RabbitMQ 곧 지원

데이터 플레인

SDK

step 안에서 추출하고, 가공하고, 적재하는 Go 라이브러리.

brevis/sdk

Gateway

HTTP POST를 받아 202로 응답하고 배치로 기록합니다. 자체 데이터베이스는 없습니다.

areteacademy/brevis-gateway

원하는 방식으로 배포

내 컴퓨터에서, 내 클러스터에서, 이미 운영 중인 런타임에서.

오픈 소스이며 셀프 호스팅: 세 곳 모두 동일한 바이너리입니다. 중간에 우리 서비스는 없습니다.

Docker Compose 권장

Postgres, Core, 콘솔, Gateway를 한 대의 머신에서. 체험하거나 개발할 때.

$ git clone https://github.com/AreteAcademy/brevis
$ cd brevis && docker compose up

Kubernetes + Helm

저장소의 차트: hook으로 실행되는 마이그레이션, 역할당 이미지 하나, step pod를 위한 최소 RBAC.

$ helm install brevis ./deployments/helm/brevis \
    --namespace data --create-namespace \
    --set database.url="postgres://…" \
    --set auth.user=admin \
    --set auth.passwordHash="$(brevis hash)" \
    --set auth.secret="$(openssl rand -base64 48)"

자체 런타임

host:가 지정된 step은 직접 운영하는 agent로 갑니다 — 라이선스, GPU, 허용 목록에 등록된 IP가 있는 곳.

# workflow step에서
host: tools

$ kubectl apply -f deployments/kubernetes/agent.yaml
