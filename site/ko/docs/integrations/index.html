문서

통합

무엇이 무엇과 연결되는지: 데이터가 어디서 오고, 어디에 도착하고, 어디서 모델링되고, 전체가 어디서 실행되는지 정리합니다.

이미 쓰고 있는 것은 모두, 아직 존재하지 않는 것은 하나도 없습니다. 드라이버는 저장소에 코드가 들어온 뒤에야 여기에 나타나며, 그 전에는 나타나지 않습니다.

각 행은 어떤 구성 요소가 어떤 패키지나 sink를 통해 해당 대상에 연결되는지, 그리고 자세한 방법은 어디서 볼 수 있는지 알려 줍니다.

데이터 가져오기#

연결 방법가이드
HTTPSDK: from.HTTPGo SDK
PostgresSDK: from/postgresGo SDK
MySQLSDK: from/mysqlGo SDK
filesSDK: from.Files — 로컬, S3, GCSGo SDK

데이터 적재 대상#

연결 방법가이드
BigQuerySDK: to/bigquery · Gateway: bigqueryGo SDK, 수집 sink
PostgresSDK: to/postgres · Gateway: postgresGo SDK, 수집 sink
MySQLSDK: to/mysql · Gateway: mysqlGo SDK, 수집 sink
RedshiftSDK: to/redshift · Gateway: redshiftGo SDK, 수집 sink
Pub/SubSDK: to/pubsub · Gateway: pubsubGo SDK, 수집 sink

파일 적재 대상#

연결 방법가이드
S3SDK: store/s3 · Gateway: s3://에 대한 filesGo SDK, 수집 sink
GCSSDK: store/gcs · Gateway: gs://에 대한 filesGo SDK, 수집 sink

모델링 대상#

연결 방법가이드
PostgresSQL: --dialect postgres (기본값)SQL
BigQuerySQL: --dialect bigquerySQL

연결 방법가이드

Kubernetesstep마다 pod 하나Kubernetes, step당 pod 하나
Helmdeployments/helm/brevis의 차트Kubernetes
