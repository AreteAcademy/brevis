deploy sesuai cara Anda

Di mesin Anda, di cluster Anda, atau di runtime yang sudah Anda kelola.

Open source dan self-hosted: binary yang sama di ketiga tempat. Tanpa layanan kami di tengah.

Docker Compose disarankan

Postgres, Core, konsol, dan Gateway di satu mesin, untuk mencoba atau mengembangkan.

$ git clone https://github.com/AreteAcademy/brevis
$ cd brevis && docker compose up
Caranya

Kubernetes + Helm

Chart di repositori: migrasi sebagai hook, satu image per peran, dan RBAC minimal untuk pod step.

$ helm install brevis ./deployments/helm/brevis \
    --namespace data --create-namespace \
    --set database.url="postgres://…" \
    --set auth.user=admin \
    --set auth.passwordHash="$(brevis hash)" \
    --set auth.secret="$(openssl rand -base64 48)"
Caranya

Runtime Anda sendiri

Step dengan host: dikirim ke agen yang Anda kelola — tempat lisensi, GPU, atau IP allowlist berada.

# di step workflow
host: tools

$ kubectl apply -f deployments/kubernetes/agent.yaml
